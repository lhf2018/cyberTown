# 上帝模式语义说明

通过 `POST /api/town/npc/{id}/god-command`，用自然语言修改指定 NPC。

## 支持字段（AI JSON + 规则增强）

- 位置 / 动作 / 目标
- 学历（关键词归一化：专科、本科、硕士、博士、985 等）
- 金钱、储蓄、负债、工作经验
- 智力、魅力、技能、知识、健康、声望
- 能量、饥饿、快乐、社交需求
- 工资：月薪 / 期权 / 年收入（元/千/万）

## 关系指令（规则解析）

对当前选中的 NPC：

- `对莉莉好感+30`
- `和老王结仇`
- `与杰克成为朋友`
- `和红姐告白` / `和红姐分手`

也可写双方：`让杰克和莉莉结仇`

## 模式与配额

- `spectator`：拒绝上帝指令
- `operator`：每次成功执行扣减 `godRemaining`（默认 5）
- Header：`X-Client-Key`（前端 localStorage 生成）

## 返回

除 `npcReply` 外，可能包含 `relationshipChange` 说明。
